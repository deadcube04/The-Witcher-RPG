# Instrucoes do projeto para o Codex

Antes de qualquer tarefa neste repositorio, leia e siga integralmente `.AGENTS/skills/no-tests/SKILL.md`. Esta skill e obrigatoria em todas as interacoes, sem excecao, inclusive antes de analisar, revisar, explicar, planejar, gerar ou alterar qualquer arquivo.

Antes de analisar, revisar, explicar, gerar ou alterar codigo, carregue as rules aplicaveis abaixo. O gatilho vale tanto para arquivos do repositorio quanto para codigo enviado no chat.

- Para React, TypeScript de frontend, TSX, JSX, Vite ou arquivos `*.ts`, `*.tsx`, `*.jsx`: leia e siga integralmente `.AGENTS/rules/React-write-rule.md` antes de trabalhar.
- Para Go, Gin, GORM ou arquivos `*.go`: leia e siga integralmente `.AGENTS/rules/Go-write-rule.md` antes de trabalhar.
- Se a tarefa envolver as duas stacks, carregue e aplique ambas.
- Se uma rule estiver ausente ou ilegivel, pare antes de analisar, revisar, explicar, gerar ou alterar o codigo em escopo e informe o bloqueio.
