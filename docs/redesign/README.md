Esta pasta registra as decisões aprovadas para a renovação visual do RPG Manager. A documentação é a fonte de verdade da implementação: mudanças de direção devem ser registradas aqui antes de chegar ao frontend.

## Estado

- Direção de produto: aprovada no GrillMe.
- Escopo funcional: preservar todas as funcionalidades existentes.
- Mídia do usuário: fora desta fase; não haverá upload nem novos campos de capa ou retrato.
- Implementação: autorizada pelo usuário após o registro destes documentos.
- Validação: lint, typecheck, build e inspeção manual; o projeto proíbe criar ou alterar testes.

## Princípio de decisão

A aplicação deve parecer um arquivo ocultista sofisticado e autoral, sem perder velocidade durante uma sessão de RPG. Atmosfera organiza e dá contexto; nunca esconde ações, reduz contraste ou retarda interação.
